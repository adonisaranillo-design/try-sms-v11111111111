🛈
Simula SY 2026-2027, Grade 11 ay gagamit na ng bagong Strengthened SHS Curriculum (3-Term, 5 Core Subjects), habang ang mga kasalukuyang Grade 12 (non-pilot) ay magpapatuloy pa sa lumang 2-Semester curriculum. Piliin mo ang tamang "Curriculum" sa Grade Input tab kada grade level.

! Danger Zone

Ingat sa mga action dito — permanente ang mga ito. Awtomatikong mag-e-export ng backup bago magpatuloy.

Simulan ang Bagong School Year
I-e-export muna nang awtomatiko ang kasalukuyang data bilang backup, tapos aalisin ang Masterlist, Grades, at Attendance (mananatili ang School Info sa Setup). Papapasukin ka ng bagong School Year.
I-reset Lahat ng Data
Buburahin ANG LAHAT — Setup, Masterlist, Grades, Attendance, Logo. Gagawing blangko ang account na ito, kasama ang cloud data kung naka-login. Kailangang i-type ang "RESET" para kumpirmahin.
